# Changelog

## 0.1.0 - 2026-09-08

- Browse wallpapers from every installed Omarchy theme in a native overlay.
- Apply a wallpaper without changing the active theme's colors.
- Keep applied copies outside Omarchy's regular background picker.
- Constrain discovery and application to installed-theme wallpaper roots.
- Bound image processing, cache growth, and retained applied state.
- Handle malformed theme data and asynchronous overlay lifecycle safely.
- Keep wallpaper selection click-committed so pointer movement cannot change the Apply target.
